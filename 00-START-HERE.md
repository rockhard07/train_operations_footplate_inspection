## 🚀 Quick Start (3 Steps)

### Step 1: Install
```bash
cd footplate-inspection-system
pip install -r requirements.txt
```

### Step 2: Configure
```bash
# Create .streamlit/secrets.toml
[supabase]
url = "https://your-project.supabase.co"
key = "your-anon-key"
```

### Step 3: Run
```bash
streamlit run app_footplate.py
```

**That's it!** App opens at `http://localhost:8501`
